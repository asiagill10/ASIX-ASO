# ASO - Administració de Sistemes Operatius

## Presentació

Soc **Asia Gill Sahota** i soc estudiant del Cicle Formatiu de Grau Superior
d'Administració de Sistemes Informàtics en Xarxa (ASIX).

Aquest repositori conté les activitats i els apunts relacionats amb
l'administració de sistemes operatius, PowerShell i el projecte MusicCloud.

## Objectiu i motivació

L'objectiu del repositori és recopilar i documentar les activitats
realitzades durant el curs, aplicar els coneixements adquirits i mantenir
una organització clara dels materials.

## Contingut del repositori

### PowerShell

Conté els apunts i les pràctiques relacionades amb PowerShell:

- Fitxers i carpetes.
- Variables.
- Tipus de dades.
- Arrays.
- Pipeline.
- `Select-Object` i `Where-Object`.
- Estructures de control.
- Scripts.
- Instal·lació de PowerShell 7 en Windows Server Core.
- Imatges de les pràctiques.

### Projecte MusicCloud

Conté les fitxes i la documentació necessàries per analitzar i dissenyar
l'organització informàtica de l'empresa.

#### Fitxes

- **Fitxa 1 — Anàlisi inicial de MusicCloud:** estudi dels treballadors,
  els departaments, els recursos i les necessitats d'accés.
- **Fitxa 2 — Organització del servei de directori de MusicCloud:**
  proposta de disseny i organització del servei de directori.

#### Presentació de l'empresa

Conté la documentació de referència proporcionada sobre MusicCloud:

- `01.Dades empresa.md`
- `02.Departaments.md`
- `03.Treballadors.md`
- `04.Perfils usuari.md`
- `05.Estructura de la informació.md`

Aquests documents permeten consultar la informació de l'empresa
necessària per resoldre les fitxes i justificar les decisions de disseny.

## Organització

Els documents s'organitzen en carpetes segons l'àrea de treball i
l'activitat corresponent, per facilitar-ne la consulta i el manteniment.
