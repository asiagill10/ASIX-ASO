# Treballar amb fitxers i carpetes

**Situació:** encara no hem estudiat les ordres de PowerShell per treballar amb fitxers i carpetes. Les haurem de descobrir utilitzant les eines d'ajuda de PowerShell.

**1. Buscar ordres**

Busca cmdlets que continguin la paraula `Item`:

```
Get-Command *Item*
```

**Captura**
![Get-Command Item](./Imatges%20Powershell/GetComand.png)
Observa les ordres que apareixen.

Intenta identificar quina ordre podria servir per:

- crear un element; `New-Item`
- eliminar un element; `Remove-Item`
- canviar el nom d'un element; `Rename-Item`
- copiar un element; `Copy-Item`
- moure un element. `Move-Item`

---

**2. Investigar una ordre**

Sense executar-la encara, consulta què fa:

```
Get-Help New-Item
```

Respon:

- Per a què serveix `New-Item`?
  El cmdlet `New-Item` serveix per **crear un element nou**, com ara una carpeta o un fitxer.
- Quina estructura té l'ordre?

```powershell
New-Item -Path <ruta> -Name <nom> -ItemType <tipus>
```

Els paràmetres principals són:

- `-Path`: indica on es crearà l'element.
- `-Name`: indica el nom de l'element.
- `-ItemType`: indica quin tipus d'element es vol crear, per exemple una carpeta (`Directory`) o un fitxer (`File`).
  Consulta alguns exemples:

```
Get-Help New-Item -Examples
```

![Get-Help New-Item -Examples](./Imatges%20Powershell/Get-help%20New-Item%20-Examples.png)

**3. Descobrir un paràmetre**

Consulta què significa el paràmetre `-ItemType`:

```
Get-Help New-Item -Parameter ItemType
```

![Get-Help New-Item -Parameter ItemType](./Imatges%20Powershell/Get-Help%20New-Item%20-Parameter%20ItemType.png)

A partir de l'ajuda, intenta descobrir com crear una carpeta.

Per exemple, haurien d'arribar a alguna cosa semblant a:

```
New-Item -ItemType Directory -Name Prova
```

![New-Item -ItemType Directory -Name Prova](./Imatges%20Powershell/New-Item%20-ItemType%20Directory%20-Name%20Prova.png)

**4. Nou repte**

Ara necessites saber com **canviar el nom de la carpeta**, però no coneixes l'ordre.

Utilitza:

```
Get-Command *Item*
```

i després consulta l'ajuda de l'ordre que creguis adequada.

L'objectiu és arribar a descobrir:

```
Rename-Item
```

i consultar:

```
Get-Help Rename-Item -Examples
```

---

Sense utilitzar Internet, descobreix quins cmdlets faries servir per:

1. crear una carpeta;
2. canviar-li el nom;
3. copiar-la;
4. moure-la;
5. eliminar-la.

**Condició:** només pots utilitzar `Get-Command` i `Get-Help` per investigar les ordres.

Descobrir ordres de xarxa amb PowerShell

## Situació

Estàs administrant un servidor Windows i necessites consultar informació de la seva configuració de xarxa.

Encara no coneixes les ordres de PowerShell relacionades amb xarxa.

La teva feina és descobrir-les utilitzant principalment:

```
Get-Command
Get-Help
```

No pots buscar les respostes a Internet.

---

## Tasques

Descobreix quines ordres de PowerShell et permeten obtenir la informació següent:

1. Mostrar els adaptadors de xarxa de l’equip.
2. Consultar les adreces IP configurades.
3. Consultar la configuració IP completa dels adaptadors de xarxa.
4. Consultar els servidors DNS configurats.
5. Comprovar si hi ha connectivitat amb un altre equip de la xarxa.

---

## Solució 4. Nou repte

Per descobrir quina ordre permet canviar el nom d'una carpeta, s'ha tornat a consultar:

```powershell
Get-Command *Item*
```

![Get-Command Item](./Imatges%20Powershell/GetComand.png)
Entre els cmdlets obtinguts s'ha identificat:

```powershell
Rename-Item
```

Per consultar com s'utilitza, s'ha executat:

```powershell
Get-Help Rename-Item -Examples
```

![Get-Help Rename-Item -Examples](./Imatges%20Powershell/Get-Help%20Rename-Item%20-Examples.png)
La comanda ha indicat que no disposava dels fitxers d'ajuda locals. Per obtenir informació sobre la sintaxi sense utilitzar Internet, s'ha utilitzat:

```powershell
Get-Command Rename-Item -Syntax
```

![Get-Command Rename-Item -Syntax](./Imatges%20Powershell/Get-Command%20Rename-Item%20-Syntax.png)
La sintaxi obtinguda mostra que podem utilitzar:

```powershell
Rename-Item -Path <ruta> -NewName <nou_nom>
```

Per tant, per canviar el nom de la carpeta `Prova` a `Prova2`, s'utilitza:

```powershell
Rename-Item -Path Prova -NewName Prova2
```

Aquesta ordre permet canviar el nom d'un element sense modificar-ne el contingut.

### Cmdlets descoberts

| Acció             | Cmdlet        |
| ----------------- | ------------- |
| Crear una carpeta | `New-Item`    |
| Canviar el nom    | `Rename-Item` |
| Copiar            | `Copy-Item`   |
| Moure             | `Move-Item`   |
| Eliminar          | `Remove-Item` |

Per descobrir aquests cmdlets s'ha utilitzat `Get-Command *Item*` i, posteriorment, `Get-Help` per consultar-ne el funcionament.
