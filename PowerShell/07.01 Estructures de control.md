## 1. Condicional

Crea:

```powershell
$port = 443
```

Mostra:

```
Port HTTPS
```

si el port és `443`.

Canvia després el valor de `$port` i comprova què passa.

## 2. if o switch

Crea:

```
$estat = 2
```

Fes que el programa mostri:

```
1 → Iniciant
2 → Executant
3 → Finalitzat
4 → En espera
qualsevol altre valor → Estat desconegut
```

Resol el problema utilitzant `if` i `switch`. Compara les dues solucions.

> `if`

## ![If](./Imatges%20Powershell/07_2_if.png)

> `switch`

## ![Switch](./Imatges%20Powershell/07_2_switch.png)

> `if`: permet comprovar condicions diferents mitjançant if, elseif i else. `switch`: permet comparar una variable amb diversos valors possibles de manera més ordenada.
> Les dues solucions funcionen correctament. En aquest exercici, switch és més senzill de llegir perquè només cal comparar una variable amb diversos valors concrets.

## 4. Condicions combinades

Crea:

```powershell
$port = 443
$actiu = $true
```

Mostra:

```text
Servei disponible
```

només quan el port sigui el 443 i estigui actiu

> Codi:

```powershell
$port = 443
$actiu = $true
if ($port -eq 443 -and $actiu -eq $true) { Write-Host "Server disponible"}
```

## 7. Objectes

Quants serveis en el teu sistema estan configurats amb el servei d'arrencada automàtic quan s'inicia l'equip?
Proposa diferents codis de resolució.

> Opció 1:

```powershell
Get-CimInstance Win32_Service | Where-Object { $_.StartMode -eq "Auto" } | Measure-Object
```

> Opció 2:

```powershell
(Get-CimInstance Win32_Service | Where-Object { $_.StartMode -eq "Auto" }).Count
```

> Opció 3:

```powershell
$serveis = Get-CimInstance Win32_Service | Where-Object { $_.StartMode -eq "Auto" }
Write-Host "Total de serveis automàtics: $($serveis.Count)"
```
