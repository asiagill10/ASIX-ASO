## 1. Comprovació de la versió actual

Abans d'instal·lar PowerShell 7, s'ha comprovat la versió de PowerShell disponible actualment al servidor.

S'ha executat:

```powershell
$PSVersionTable
```

El servidor disposava inicialment de **Windows PowerShell 5.1**.
