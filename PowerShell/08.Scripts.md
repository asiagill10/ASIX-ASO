# Scripts PowerShell

L'objectiu d'aquesta pràctica és integrar els conceptes treballats durant la introducció a PowerShell:

- variables;
- tipus de dades;
- arrays;
- pipeline;
- `Select-Object`;
- `Where-Object`;
- propietats dels objectes;
- `if`, `elseif`, `else` i `switch`;
- `foreach` i `ForEach-Object`;
- scripts `.ps1`.

> **Important:** abans d'incorporar una ordre al script, és recomanable provar-la directament a la consola de PowerShell.

# 1. Informació bàsica del sistema

Crea un script anomenat:

```
infoSistema.ps1
```

El script ha de mostrar:

- nom de l'equip;
- usuari actual;
- versió de PowerShell;
- data i hora actuals;
- directori actual.

La sortida ha de ser clara i llegible.

Per exemple:

```
===== INFORMACIÓ DEL SISTEMA =====

Equip: ...
Usuari: ...
PowerShell: ...
Data: ...
Directori actual: ...
```

1. Adjunta el script final.

```powershell
$nomEquip = Hostname
$usuariActual = $env:USERNAME
$versioPowerShell = $PSVersionTable.PSVersion
$dataActual = Get-Date
$directoriActual = Get-Location

Write-Host "===== INFORMACIO DEL SISTEMA ====="
Write-Host ""
Write-Host "Equip: $nomEquip"
Write-Host "Usuari: $usuariActual"
Write-Host "PowerShell: $versioPowerShell"
Write-Host "Data: $dataActual"
Write-Host "Directori actual: $directoriActual"
```

# 2. Estat dels serveis

Crea:

```
estatServeis.ps1
```

El script ha de:

1. obtenir tots els serveis del sistema;
2. comptar quants estan en execució;
3. comptar quants no estan en execució;
4. mostrar el total de serveis;
5. mostrar els resultats al final.

Exemple:

```
===== ESTAT DELS SERVEIS =====

Total: 230
Running: 95
Not running: 135
```

1. Adjunta el script final.

```powershell
$serveis = Get-Service

$serveisExecucio = $serveis | Where-Object {$_.Status -eq "Running"}
$serveisAturats = $serveis | Where-Object {$_.Status -ne "Running"}
$serveisTotal = $serveis.Count
Write-Host "===== ESTAT DELS SERVEIS ====="
Write-Host "Total: $serveisTotal"
Write-Host "Running: " $serveisExecucio.Count
Write-Host "Not running: " $serveisAturats.Count
```

# 3. Processos amb més consum de CPU

Crea:

```
topProcessos.ps1
```

El script ha de mostrar els **10 processos amb més consum de CPU**.

La sortida ha de mostrar únicament:

```
Name
Id
CPU
```

Després mostra també:

```
Nombre total de processos: ...
```

1. Adjunta el script final.

```powershell
$processos = Get-Process

$top10Processos = $processos | Sort-Object CPU -Descending | Select-Object -First 10 Name, Id, CPU
$processosTotal = $processos.Count

$topProcessos | Format-Table -AutoSize
Write-Host ""
Write-Host "Nombre total de processos: $processosTotal"
```

# 4. Anàlisi de fitxers d'una carpeta

Crea:

```
analitzaCarpeta.ps1
```

El script ha de treballar amb la carpeta des d'on s'executa.

Ha de mostrar:

- nombre total d'elements;
- els cinc fitxers més grans;
- nom i mida d'aquests fitxers.

Investiga les propietats retornades per:

```
Get-ChildItem
```

i utilitza-les per construir el pipeline.

> Tingues en compte que pots trobar tant fitxers com carpetes.

1. Adjunta el script final.

```powershell
$elements = Get-ChildItem
$fitxers = Get-ChildItem -File

$fitxersMesGrans = $fitxers | Sort-Object Length -Descending | Select-Object -First 5 Name, Length

Write-Host "===== ANALISI DE LA CARPETA ====="
Write-Host ""
Write-Host "Nombre total d'elements: $($elements.Count)"
Write-Host ""
Write-Host "===== 5 FITXERS MES GRANS ====="
$fitxersMesGrans
```

## ![Script 4](./Imatges%20Powershell/asia_analitzarCarpetes.png)

2. Explica el procés que has seguit o operacions que has executat abans d'obtenir el script final.

```powershell
Get-ChildItem
Get-ChildItem -File
Get-ChildItem -File | Sort-Object Length -Descending
Get-ChildItem -File | Sort-Object Length -Descending | Select-Object -First 5 Name, Length
```

> He utilitzat Get-ChildItem per obtenir els elements de la carpeta actual i comptar-los. Després, he utilitzat Get-ChildItem -File per obtenir només els fitxers, excloent les carpetes. Finalment, he ordenat els fitxers segons la propietat Length, de més gran a més petit, i he seleccionat els cinc primers amb el seu nom i la seva mida en bytes.

# 5. Diagnosi bàsica del sistema

Crea:

```
diagnosi.ps1
```

Ha de mostrar almenys quatre apartats.

## Processos

Mostra els cinc processos amb més CPU.

Propietats:

```
Name
Id
CPU
```

## Serveis

Mostra:

```
Total de serveis
Serveis en execució
Serveis no executats
```

## Fitxers

Mostra els tres fitxers més grans de la carpeta actual.

Propietats:

```
Name
Length
```

## Estat final

Al final mostra un petit resum:

```
===== RESUM =====

Processos analitzats: ...
Serveis analitzats: ...
Fitxers analitzats: ...
```

Organitza el script perquè sigui fàcil de llegir.

Pots utilitzar comentaris per separar els diferents blocs:

```
# =====================
# PROCESSOS
# =====================
```

1. Adjunta el script final.

```powershell
# =====================
# PROCESSOS
# =====================

$processos = Get-Process

$topProcessos = $processos | Sort-Object CPU -Descending | Select-Object -First 5 Name, Id, CPU
Write-Host "===== PROCESSOS ====="
$topProcessos | Format-Table -AutoSize
Write-Host ""


# =====================
# SERVEIS
# =====================

$serveis = Get-Service
$serveisEnExecucio = $serveis | Where-Object { $_.Status -eq "Running" }
$serveisNoExecutats = $serveis | Where-Object { $_.Status -ne "Running" }

Write-Host "===== SERVEIS ====="
Write-Host "Total de serveis: $($serveis.Count)"
Write-Host "Serveis en execucio: $($serveisEnExecucio.Count)"
Write-Host "Serveis no executats: $($serveisNoExecutats.Count)"
Write-Host ""


# =====================
# FITXERS
# =====================

$fitxers = Get-ChildItem -File
$topFitxers = $fitxers | Sort-Object Length -Descending | Select-Object -First 3 Name, Length

Write-Host "===== FITXERS ====="
Write-Host "===== 3 FITXERS MES GRANS ====="
$topFitxers | Format-Table -AutoSize
Write-Host ""


# =====================
# RESUM FINAL
# =====================

Write-Host "===== RESUM ====="
Write-Host "Processos analitzats: $($processos.Count)"
Write-Host "Serveis analitzats: $($serveis.Count)"
Write-Host "Fitxers analitzats: $($fitxers.Count)"
```

Finalment, he integrat totes aquestes operacions en un únic script, organitzat en quatre apartats, amb un resum final de les dades obtingudes.

# Requisits generals

Tots els scripts han de:

1. tenir extensió `.ps1`;
2. executar-se amb PowerShell 7;
3. utilitzar noms de variables descriptius;
4. tenir el codi correctament indentat;
5. incloure algun comentari quan sigui necessari;
6. evitar codi que no sigui necessari;
7. mostrar una sortida comprensible per a l'usuari.

Abans de donar un script per acabat:

```
prova cada part a la consola
        ↓
comprova el resultat
        ↓
incorpora-la al script
        ↓
executa el script complet
```
