# Treballar amb variables

## 1. Crear variables

Crea les variables següents:

```
$nom
$servidor
$ip
$port
```

Assigna-hi valors.

Per exemple:

```
$nom = "Pere"
```

Mostra després el contingut de cadascuna de les variables.
S'han creat quatre variables i se'ls han assignat diferents valors:

```powershell
$nom = "Pere"
$servidor = "SRV01"
$ip = "192.168.1.10"
$port = 8080
```

## 2. Modificar una variable

Crea:

```

$servidor = "SRV01"

```

Mostra el seu valor.

Després canvia'l per:

```

SRV02

```

Comprova quin valor conserva la variable.

## 3. Operacions

Crea dues variables:

```

$num1 = 20
$num2 = 5

```

Crea una tercera variable que guardi:

- la suma;
- la resta;
- la multiplicació;
- la divisió.

Per exemple:

```

$resultat = $num1 + $num2

```

Mostra cada resultat.

## 5. Cometes

Executa:

```

$servidor = "SRV01"

```

Després:

```

Write-Host "Servidor: $servidor"

```

i:

```

Write-Host 'Servidor: $servidor'

```

## ![Cometes](./Imatges%20Powershell/VariablesCometes.png)

Respon:

**Quina diferència observes? Per què creus que passa?**
La diferència és que les cometes dobles permeten interpretar les variables que hi ha dins del text, mentre que les cometes simples tracten el contingut com a text literal.

---

## 6. Guardar el resultat d'una ordre

Executa:

```

$serveis = Get-Service

```

Després:

```

$serveis

```

Respon:

- Què creus que conté $serveis?
- La variable conté un únic valor o diversos elements?

Fes el mateix amb:

```

$processos = Get-Process

```

i comprova el seu contingut.

## 7. Aplicació a administració

Crea una variable:

```

$nomServei = "Spooler"

```

Utilitza aquesta variable per consultar el servei amb:

```

Get-Service -Name ...

```

L'objectiu és obtenir el mateix resultat que:

```

Get-Service -Name Spooler

```

però **sense escriure `Spooler` directament en el cmdlet**.
