# Arrays

## 1. Crear un array

Crea un array amb aquests servidors:

```
SRV01
SRV02
SRV03
SRV04
```

Guarda'l dins de:

```powershell
$servidors
```

Mostra tot el contingut de l'array.

## ![Crear un array](./Imatges%20Powershell/CrearArray.png)

## 2. Accedir a posicions

Amb l'array anterior, mostra:

- el primer servidor;
- el segon servidor;
- el quart servidor.

## ![Accedir a posicions](./Imatges%20Powershell/ArrayMostrarServidors.png)

Respon:

**Quina és la posició del primer element d'un array?**
La posició del primer element és la 0.

## 3. Comptar elements

Utilitza:

```powershell
.Count
```

per saber quants servidors hi ha dins de l'array.

Afegeix:

```
SRV05
```

i torna a comprovar el nombre d'elements.

## ![Comptar elements](./Imatges%20Powershell/ArrayComptarElements.png)

## 4. Modificar un element

Partint de:

```powershell
$servidors = "SRV01", "SRV02", "SRV03"
```

modifica el segon element perquè passi a ser:

```text
SRV-WEB01
```

Mostra després tot l'array.

## ![Modificar un element](./Imatges%20Powershell/ArrayModificarElement.png)

## 5. Array de ports

Crea un array numèric amb els següents ports: 22, 80, 443 i 3389

Respon (i digues quina comanda has executat per obtenir la resposta):

## ![Array de ports](./Imatges%20Powershell/ArrayArrayPorts.png)

- Quants ports hi ha?
  4

```powershell
$ports.Count
```

- Quin és el primer?
  22

```powershell
$ports[0]
```

- Quin és l'últim?
  3389

```powershell
$ports[-1]
```

O també:

```powershell
$ports[0]
```

- Quin tipus té el primer element?
  Int32

```powershell
$ports[0].GetType().Name
```

## 8. General

Crea un array:

